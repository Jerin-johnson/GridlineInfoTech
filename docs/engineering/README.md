# Engineering Guidelines

This directory contains the engineering standards and development guidelines followed throughout the Automotive E-Commerce Platform.

These guidelines ensure consistency, maintainability, readability, and a predictable development workflow.

## Guidelines

| Document                                      | Description                                                                                            |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------ | --- |
| [Naming Conventions](./naming-conventions.md) | Naming standards for files, folders, variables, functions, types, components, and other code entities. |     |
| [Branching Strategy](./branching-strategy.md) | Branch naming, branch responsibilities, and how changes move between branches.                         |
| [Commit Conventions](./commit-conventions.md) | Standard format for writing consistent and meaningful commit messages.                                 |

## Guideline Principles

- Keep code readable and maintainable.
- Prefer consistency over personal coding preferences.
- Use meaningful names.
- Keep changes focused and small.
- Avoid unnecessary complexity.
- Follow established conventions throughout the codebase.
- Update relevant documentation when implementation changes affect documented behavior.

## Scope

These guidelines apply to all parts of the project, including frontend, backend, shared types, configuration, scripts, and tests.

Guidelines may be updated when necessary, provided the changes improve consistency, maintainability, or development efficiency.
